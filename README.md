## 🚀 Getting Started

### Prerequisites

- Python 3.x
- Jupyter Notebook or JupyterLab

### Installation

Install NumPy using pip:

```bash
pip install numpy
```

### Run the Notebook

1. Clone this repository:

   ```bash
   git clone https://github.com/priyam-shankar/numpy-learning.git
   ```

2. Navigate to the project directory:

   ```bash
   cd numpy-learning
   ```

3. Launch JupyterLab:

   ```bash
   jupyter lab
   ```

4. Open `01_numpy_intro.ipynb` and start exploring the code.
